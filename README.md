About kernels
=============

Home: https://github.com/huggingface/kernels

Package license: Apache-2.0

Summary: Download compute kernels

Development: https://github.com/huggingface/kernels

Documentation: https://huggingface.co/docs/kernels

kernels lets you load and run pre-compiled compute kernels from the Hugging Face
Hub directly in Python, without building them locally.
